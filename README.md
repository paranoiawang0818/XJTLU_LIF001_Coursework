# Honor of Kings AI Assistant Prototype

A high-fidelity web prototype for an AI-powered game assistant inspired by Honor of Kings.

## Overview

This project is a static front-end prototype that demonstrates how an AI assistant could:

- analyze recent player performance
- track playtime habits
- explain why a certain AI difficulty is recommended
- automatically adjust training or challenge intensity based on player state

The experience is designed as a multi-screen flow:

1. Login and account binding
2. Game assistant initial screen
3. Player performance dashboard
4. Playtime tracking page

## Core Idea

The main concept of this prototype is **adaptive AI difficulty recommendation**.

Instead of showing a fixed difficulty level, the interface explains how AI evaluates player data such as:

- win rate
- KDA
- teamfight participation
- gold conversion
- death rate
- hero pool stability
- performance variance
- late-night play ratio
- long-session fatigue

Based on these signals, the assistant recommends modes such as:

- Stable Progression
- High Pressure Combat
- Recovery Training

## Features

- Separate login screen before any player data is shown
- Post-login game-style assistant homepage
- Player dashboard with performance metrics and trend visualization
- Explainable AI recommendation flow
- Difficulty adjustment history
- Playtime tracking with fatigue-aware suggestions
- Mock data driven interface with static HTML, CSS, and JavaScript
- Responsive layout for desktop and mobile

## Tech Stack

- HTML
- CSS
- JavaScript

## Notes

- This is a front-end prototype only
- No real Honor of Kings API is connected
- All player stats and AI recommendations use mock data
- The project focuses on presentation, interaction flow, and visual storytelling

## Purpose

This prototype is intended for:

- concept demos
- portfolio presentation
- product visualization
- future expansion into a real assistant dashboard
